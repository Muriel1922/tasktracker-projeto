
# TaskTracker

## Sobre o projeto
O TaskTracker é um sistema de gerenciamento de tarefas acadêmicas desenvolvido em Python para a disciplina de Bootcamp II.

O objetivo é ajudar estudantes a organizar suas atividades, acompanhar prazos e gerenciar tarefas.

## Funcionalidades planejadas
- Cadastrar novas tarefas.
- Visualizar tarefas cadastradas.
- Informar título, disciplina e prazo.
- Definir a prioridade das tarefas.
- Acompanhar o status das atividades.
- Validar as informações inseridas.

## Funcionalidades implementadas
- Menu principal interativo.
- Navegação entre as opções do menu.
- Opção para encerrar o programa.
- Tratamento de opções inválidas.

## Tecnologias utilizadas
- Python 3
- Visual Studio Code
- Git e GitHub (versionamento do projeto)

## Como executar
1. Instale o Python 3.
2. Abra a pasta do projeto no terminal.
3. Execute:

    python src/main.py
